# Menu bar

Alveary's menu bar item lists your five most recent threads, plus New Thread, Open Alveary, Settings, and Quit. Above them, **Needs review** lists pull requests waiting on your review, using the Pull requests screen's status, repository, and ignored filters, and leaving out any you've handed to an agent review until that review is submitted. A dot on the icon says when any are waiting, and picking one opens it on the Pull requests screen. The list refreshes in the background every fifteen minutes by default.

Closing the main window doesn't quit Alveary: agent runs, scheduled tasks, and the app-shot shortcut keep going, and clicking the Dock icon or **Open Alveary** brings the window back. **Settings → Menu bar** turns the item or its review list off and changes the refresh interval.

**Launch at startup**, in the same tab, registers Alveary as a login item. macOS owns that registration, so the switch follows System Settings → General → Login Items.
